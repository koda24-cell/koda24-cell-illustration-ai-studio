# コタマのぼうけんでの利用

このリポジトリは汎用の制作環境です。コタマの素材制作にも使えますが、**正式素材はコタマ側のルールでのみ採用**します。

## 使い方
1. 制作指示の `assign_to` に `project: kotama-no-bouken` と予定の割当先（キャラ名・敵名・画面名）を書く（予定であり採用ではない）。
2. `produce` で制作 → サイトで確認 → ユーザーが `approvals/approvals.yaml` に「承認」と割当先を記入。
3. 承認済みの画像だけを、コタマ側のルールに従って反映する:
   - `koda24-cell/kotama-no-bouken` の AGENTS.md / CLAUDE.md、素材管理・承認ルール（正式素材の昇格はそちらの手順）
   - `koda24-cell/kotama-3d-progress` の AGENTS.md「イラスト制作管理」: `illustrations.json` への登録は機能ブランチ/PR、固定コミット URL、
     `assigned_to` と `assignment_checked_sha`、承認・用途・担当は根拠がなければ未確認/null、既存データを上書き・消去しない。
4. コタマへ反映する PR には、元の `run_id`・ステージ・使用モデル（ID と SHA256）・ライセンス確認結果・承認記録を記載する。

## してはいけないこと
- 未承認の生成物をコタマの正式フォルダへ置く・ゲームに組み込む。
- 非公開の参考画像（Pinterest 参考・個人資料等）や、その派生物を公開リポジトリ・公開サイトへ出す。
- このリポジトリからコタマへ自動 push する仕組みを作る（反映は常に人の承認後、コタマ側の PR で）。
